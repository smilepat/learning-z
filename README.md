# learning-z

ReadStep (가칭) · 단계별 영어 읽기 서비스 프로토타입 v0.7

초등 영어 학습자가 자기 단계의 책을 듣고, 읽고, 문장을 다시 세우며 익히는 웹 서비스의 프로토타입입니다. 참고한 서비스와 무엇이 왜 다른지는 `docs/DIFFERENTIATION.md`에 있습니다.
설치와 빌드가 필요 없습니다. 폴더를 내려받아 `index.html`을 열면 동작합니다.

- 사이트: https://smilepat.github.io/learning-z/
- 개발 현황판(전체 내용 보기): https://smilepat.github.io/learning-z/dev/
- 책 검사 도구: https://smilepat.github.io/learning-z/tools/check.html

## 만드는 방식 (REA)

이 프로젝트는 REA(Reverse Engineering Application) 방식을 따릅니다. 참고 서비스의 **공개된 모습만** 관찰해 업무 흐름을 참고하고, 책, 그림, 화면, 규칙은 모두 새로 만듭니다.

- 관찰한 사실과 가져오지 않은 것: `docs/REA_ANALYSIS.md`
- 데이터 출처와 검수 상태: `docs/DATA_SOURCES.md`
- 결정 기록(사용자 결정과 에이전트 가정을 나눠 적음): `docs/HANDOFF.md`
- 한눈에 보는 상태: `STATUS.md`

이어서 작업할 때는 "docs/HANDOFF.md와 STATUS.md 읽고 이어서 진행해줘"로 시작합니다.

## 개발 참여자라면

개발 현황판 하나만 보면 됩니다. 모든 책의 본문과 그림, 퀴즈와 정답, 단계 기준, 단계 진단 글, 그림 전체, 낱말 풀이, 화면별 주소, 할 일과 변경 기록이 한 화면에 있습니다.
데이터 파일을 직접 읽어 그리므로 책을 고치면 현황판도 함께 바뀝니다. 할 일과 변경 기록은 `data/project.js`를 고칩니다.
의견은 GitHub Issues에 남깁니다.

현황판에서 할 수 있는 일:

- **검수**: "검수" 구역에서 이름을 적고 검수 모드를 켠 뒤, 줄마다 통과 / 고침 / 빼기를 누릅니다. 결과는 복사하거나 GitHub 이슈로 보냅니다. 판정은 그 기기에만 저장됩니다.
- **기기 점검**: "기기 점검" 구역에서 소리, 녹음, 기록 저장이 되는지 버튼으로 확인합니다.

## 들어 있는 것 (v0.6)

- 6단계, 책 30권(단계마다 5권), 퀴즈 150문항, 그림 38종
- 학생: 단계 진단, 내 서재, 듣기, 낱말 뜻, 끊어 읽기, 소리 글자 표시(1단계), 녹음, 다시 세우기, 확인 문제, 독서 도장판, 내 낱말장
- 선생님: 학급 현황, 문제 유형별 정답률, 어디서 막히는지, 숙제 지정, 책별 수업안, 인쇄용 책
- 학부모: 읽기 기록, 집에서 돕는 방법
- 기록 코드 / 숙제 코드: 서버 없이 학생 기기와 선생님 기기 사이에 기록과 숙제를 전달

## 책을 추가하려면

`docs/level-guide.md`를 보고 `data/books.js`에 책을 붙인 뒤, `tools/check.html`을 열어 오류가 0건인지 확인합니다.

## 알려진 한계

- 서버와 로그인이 없습니다(나중에 하기로 함). 학습 기록은 각 기기의 브라우저에만 저장되고, 앱에는 자동으로 밖에 보내는 코드가 없습니다. 음성 읽기는 브라우저 기능이라 기기에 따라 온라인 음성이 쓰일 수 있습니다.
- 개발 현황판은 퀴즈 정답까지 보여 주는 개발 단계용 화면입니다.
- 기록 코드는 암호화되어 있지 않아 내용을 고칠 수 있습니다. 평가용으로는 적합하지 않습니다.
- 음성은 브라우저의 기본 영어 음성을 씁니다. 기기에 따라 소리가 나지 않을 수 있습니다.
- 본문과 퀴즈는 AI가 쓴 초안입니다. 두 AI 모델의 1차 검수(2026-11-18, 기록은 `data/review.js`)와, 그중 사람이 판단할 9건에 대한 결정(이슈 #1)은 반영했습니다. v0.6에서 추가한 책 12권도 같은 방식의 AI 검수를 거쳤습니다. 본문과 퀴즈 전체에 대한 사람의 줄별 검수는 아직 받지 않았습니다.
- 단계 기준과 단계 진단 규칙은 잠정입니다.
- 선생님 화면은 가져온 학생 기록이 없으면 예시 데이터를 보여 줍니다.
- 이름 "ReadStep"은 가칭입니다.

## 색상 원칙

밝고 차분한 화면 위에 자연스러운 색의 낱말 그림을 둡니다.
그림은 뜻을, 보라색 밑줄은 이번에 배울 글자를, 파란 버튼은 행동을 안내합니다.
문제의 정답을 색이나 위치로 암시하지 않습니다.
