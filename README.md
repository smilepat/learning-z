# learning-z

ReadStep (가칭) · 단계별 영어 읽기 서비스 프로토타입 v0.2

초등 영어 학습자가 자기 단계의 책을 듣고, 읽고, 퀴즈로 확인하는 웹 서비스의 프로토타입입니다.
설치와 빌드 없이 `index.html` 파일 하나로 동작합니다.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 현재 버전 (v0.2) |
| `readstep-prototype-v0.1.html` | 이전 버전 (v0.1, 1~3단계 9권) 보존용 |

## 들어 있는 것 (v0.2)

- 6단계, 책 15권, 퀴즈 75문항, 그림 32종 (이야기와 그림은 이 프로토타입을 위해 새로 만든 것)
- 학생: 내 서재, 듣기, 낱말 뜻, 소리 글자 표시(1단계), 녹음, 퀴즈, 별
- 선생님: 학급 현황, 문제 유형별 정답률, 숙제 지정, 책별 수업안, 인쇄용 책
- 학부모: 읽기 기록, 집에서 돕는 방법
- 기록 코드 / 숙제 코드: 서버 없이 학생 기기와 선생님 기기 사이에 기록과 숙제를 전달

## 쓰는 방법

`index.html`을 내려받아 브라우저에서 엽니다.
레포를 공개로 바꾸고 GitHub Pages를 켜면 주소 하나로 접속할 수 있습니다.

## 알려진 한계

- 서버가 없습니다. 학습 기록은 각 기기의 브라우저에만 저장됩니다.
- 기록 코드는 암호화되어 있지 않아 내용을 고칠 수 있습니다. 평가용으로는 적합하지 않습니다.
- 음성은 브라우저의 기본 영어 음성을 씁니다. 기기에 따라 소리가 나지 않을 수 있습니다.
- 4~6단계는 단계마다 책이 2권뿐입니다.
- 선생님 화면은 가져온 학생 기록이 없으면 예시 데이터를 보여 줍니다.
- 이름 "ReadStep"은 가칭입니다.

## 색상 원칙

밝고 차분한 화면 위에 자연스러운 색의 낱말 그림을 둡니다.
그림은 뜻을, 보라색 밑줄은 이번에 배울 글자를, 파란 버튼은 행동을 안내합니다.
문제의 정답을 색이나 위치로 암시하지 않습니다.
