# 참고 서비스와 다르게 만드는 계획

작성: 2026-11-19 · 상태: v0.7에 반영. 2026-11-19에 공개 사이트에 올림(사용자 요청).

## 1. 원칙

1. **겉이 아니라 학습 방식이 달라야 한다.** 색이나 이름만 바꾸는 것은 차별화로 세지 않는다.
2. **모든 차이는 개선이어야 한다.** "다르게 보이려고" 넣은 것은 빼고, 한국 초등 영어 학습자에게 더 나은 이유가 있는 것만 넣는다.
3. **비교 대상은 공개된 사실뿐이다.** 참고 서비스의 학생 화면은 보지 않았다(가입, 체험판 금지). 그래서 "화면이 다르다"는 확인할 수 없고, 아래 표의 참고 서비스 칸은 `docs/REA_ANALYSIS.md`의 사실 번호(F)로만 채웠다. 번호가 없는 칸은 "모름"이다.
4. **우리 것에서 출발한다.** 차이의 재료는 발주자의 다른 작업(끊어 읽기 `chunk-reading`)과 대상 학습자(영어를 외국어로 배우는 한국 초등학생)에서 가져왔다.

## 2. 지금까지 닮았던 점 (솔직한 진단)

v0.6까지의 흐름은 "단계별 서재 → 듣기 → 읽기 → 퀴즈 → 별 → 단계 올라가기"였다. 공개된 사실만 놓고 봐도 참고 서비스와 뼈대가 같았다.

| 닮은 점 | 근거 |
|---|---|
| 책을 듣고 읽고 퀴즈를 푸는 흐름 | F-2, F-10 |
| 퀴즈 80% 통과 | F-10 |
| 그 단계의 책을 **전부** 마쳐야 다음 단계 | F-10 (구조까지 같았음) |
| 별을 모으는 보상 | F-2, F-13 나 |
| 교사 화면이 점수와 진도 중심 | F-4 |

## 4. 이번에 바꾼 것 (v0.7)

- 흐름: 듣기 → 읽기 → **다시 세우기** → 확인 문제. 읽기의 마지막 쪽 버튼이 "다시 세우기"로 간다
- `js/chunk.js`: 끊어 읽기 규칙. AI를 쓰지 않는 규칙 기반이라 같은 글에는 늘 같은 결과가 나온다
- 별 점수를 없애고 도장으로 바꿈. 이름도 "퀴즈"에서 "확인 문제"로 바꿈(시험이 아니라 확인이라는 뜻)
- 단계 올라가기: 5권 전부 → 4권
- 내 낱말장 화면(`#words`), 학부모와 선생님 화면의 "어디서 막히나요"
- 기록 코드에 자주 누른 낱말과 막힌 쪽이 함께 담김
- 끊어 읽기 규칙을 30권 전체에 대어 보고 고침. 다른 AI 모델의 검수를 받아 반영함 (`docs/chunk-review-2026-11-19.md`)
- 덩어리별 우리말 풀이 시범: My Red Bus(2단계), The Lost Ball(3단계), Where Does Rain Come From?(5단계). `data/chunks-ko.js`

## 5. 한계와 확인이 필요한 것

- **끊어 읽기 규칙은 에이전트가 정한 잠정 규칙이다.** 전치사와 접속사 앞, 쉼표 뒤에서 끊고, 끊을 곳이 마땅치 않으면 표시하지 않는다. 한 번 훑어보고 고쳤고 다른 AI 모델의 검수도 받았지만 **사람은 보지 않았다.** 사람이 봐 주면 좋은 곳은 `docs/chunk-review-2026-11-19.md` 5절에 있다
- 다시 세우기 문장 90개는 규칙이 고른다. 순서를 바꿔도 말이 되는 문장과 단계에 비해 쉬운 문장이 섞여 있다(검수에서 13건 지적, 9건은 고르지 않게 했고 4건은 남음). 순서가 다르면 "책의 문장과 순서가 달라요"라고 안내한다. 책마다 사람이 문장을 골라 주는 기능은 아직 없다
- 덩어리별 우리말 풀이는 AI 초안이다. 직독직해 식 풀이가 아이에게 도움이 되는지, 어색한 우리말에 익숙해지게 하는 것은 아닌지는 교사의 판단이 필요하다
- "4권"은 근거가 약한 임시값이다(5권 중 한 권의 여유). 책 수가 바뀌면 다시 본다
- 이 방식이 실제로 더 잘 가르치는지는 **검증하지 않았다.** 아이가 써 본 기록이 없다
- 참고 서비스의 학생 화면을 보지 않았으므로, 그쪽에 비슷한 활동이 있는지는 모른다. 위 표는 "공개된 사실과 비교한 차이"이지 "그쪽에 없는 기능"이라는 주장이 아니다
- 화면 생김새(색, 글꼴, 배치)는 발주자의 색상 지침을 따른 것이고 이번에 바꾸지 않았다
