- 1단계(1-x)와 2단계(2-x) 묶음 시간은 중앙값이 비슷했다(1단계 87분, 2단계 약 80분). 이 범위(19~124낱말)에서는 글 길이보다 묶음마다 드는 고정 작업(표지, 기록, 업로드)이 시간을 더 좌우했다.

## 4. 사람이 볼 양 (실측 + 가정)

- 검수 시트 줄: 시범 150권 약 2,040줄(권당 약 13.6줄: 제목 1, 본문 쪽, 퀴즈 5, 표지 1). 전체 180권 2,430줄.
- 표지 중 사람 판단이 필요하다고 표시한 것: 75장 / 149장 (**약 50%**). 인물이 책마다 달라 보임, 전통 의상·삿갓·사원 같은 고정관념 소품.
- 검수 시간(가정): 한 줄에 30~60초면 시범 150권 약 17~34시간. 검수자 1명이 주 10시간이면 2~4주.

## 5. 재지 못한 것

- **비용**: 글 생성 토큰, 그림 생성 크레딧 사용량 기록이 없음. 2단계부터 묶음마다 기록한다.
- **장면 그림**: 시범은 표지만 AI로 만들고 쪽 그림은 SVG 낱말 그림을 썼다. 기획서 8절의 "쪽마다 장면 그림 1장"(1,500권 약 16,500장)은 시범에서 시간과 실패율을 재지 않았다.
- **음성**: 지금은 브라우저 기본 음성이다. 녹음이나 TTS 파일 제작 시간은 재지 않았다.
- **긴 글**: 3단계 이상(140~3,000낱말, 8~32쪽)은 만들어 보지 않았다.

## 7. 다시 짠 일정 (가정)

**2단계: Word Spotter, Sentence Builder 나머지 545권**
- 시범 속도(10권 약 87분)라면 에이전트 작업 약 55묶음, 약 80시간.
- 실제 속도를 정하는 것은 사람 쪽이다. 묶음은 사용자가 "다음 작업"을 줄 때마다 1~3개씩 진행됐다. 하루 2~3묶음이면 약 4~6주.
- 사람 검수: 2단계 전체(1~2단계 720권) 약 9,800줄. 한 줄 30~60초, 주 10시간이면 약 8~16주. **검수가 제작보다 느리다.**

**권장 순서**
1. 표본 검수 먼저(1주): 레벨마다 2권씩 20권(약 270줄)과 표지 75장을 사람이 본다. 반복되는 문제(문체, 퀴즈 유형, 그림 소품)를 찾아 규칙과 프롬프트를 고친 뒤 대량 제작한다. 문제가 545권에 복제되는 것을 막기 위해서다.
2. 2단계 제작: 표본 검수 반영 뒤 10권 묶음으로 진행. 묶음마다 걸린 시간, 그림 생성 횟수와 실패, 비용을 기록한다.
3. 시범 나머지 검수: 제작과 함께 진행. 1단계 완료 기준(사람 검수 100%)은 이때 채운다.
4. 3단계 시범 10권: Story Walker 3-1~3-4에서 10권을 먼저 만들어 긴 글의 시간과 그림 수를 잰 뒤 3단계 이후 일정을 정한다. 지금 값으로 3단계 이상을 계산하면 오차가 크다.

## 8. 정할 것

1. 장면 그림 범위: 1~2단계는 지금처럼 표지 1장 + SVG 낱말 그림으로 갈지(에이전트 추천), 쪽마다 장면 그림을 넣을지. 넣으면 1~2단계 남은 약 3,750쪽 분량의 그림이 더 든다.
2. 표본 검수를 먼저 하고 2단계를 시작할지(에이전트 추천), 바로 시작할지.
3. 비용 기록 방법: 그림 생성 크레딧과 글 생성 사용량을 어디서 확인할지.
