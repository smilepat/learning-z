# 프로젝트 범위 (Scope) — ReadStep (가칭)

작성: 2026-11-19 · 기준 버전: v0.8 · 레포: `smilepat/learning-z`

이 문서는 "이 프로젝트가 무엇을 하고 무엇을 하지 않는지"를 한곳에 모은 것이다.
각 항목에는 누가 정했는지를 적었다. **사용자** = 발주자가 정함, **가정** = 에이전트가 정했고 확정 전, **대기** = 아직 정하지 않음.

---

## 1. 한 줄 정의

영어를 외국어로 배우는 어린 학습자가 자기 단계의 영어책을 **듣고, 읽고, 문장을 다시 세우며** 익히는 단계별 읽기 웹 서비스.
**첫 대상은 중국 학습자이고, 아시아 영어 교육(ELT) 시장에서 두루 쓸 수 있는 제품**을 목표로 한다(사용자, 2026-11-19). 그래서 화면과 책에 딸린 글은 모두 영어이고, 특정 나라의 말은 선택 언어 묶음으로 따로 둔다.
선생님과 학부모는 점수보다 **아이가 어디서 막히는지**를 본다.

기존의 단계별 읽기 서비스(Learning A-Z 계열)를 대신할 독립 서비스를 만드는 것이 출발점이며(사용자, 2026-11-17), 겉모습만이 아니라 학습 방식이 달라야 한다(사용자, 2026-11-19).

## 2. 목표와 목표가 아닌 것

| 목표 | 목표가 아닌 것 |
|---|---|
| 단계에 맞는 책을 스스로 읽는 연습 | 참고 서비스의 복제나 호환 |
| 문장을 뜻 덩어리로 읽고 다시 만들어 보는 연습 | 시험 점수 산출, 공식 평가 |
| 교사가 숙제를 내고 막힌 곳을 보는 것 | 학교 행정 시스템 연동 |
| 서버 없이도 돌아가는 시제품으로 방식을 먼저 검증 | 지금 단계에서의 유료 판매 |
| 모든 콘텐츠를 새로 만들고 출처와 검수 상태를 드러냄 | 외부 교재나 저작물의 활용 |

## 3. 대상 사용자

| 사용자 | 하는 일 | 상태 |
|---|---|---|
| 학생 | 단계 진단, 책 읽기, 다시 세우기, 확인 문제, 낱말장 | 만듦 |
| 선생님 | 학급 현황, 막힌 곳 보기, 숙제 지정, 수업안, 인쇄용 책 | 만듦 (서버가 없어 기록은 코드로 주고받음) |
| 학부모 | 읽기 기록과 막힌 곳 보기, 집에서 돕는 방법 | 만듦 (같은 기기의 기록만) |
| 개발 참여자 | 개발 현황판에서 전체 내용과 할 일 보기, 검수 | 만듦 |

**대상 학습자는 정해졌다(사용자, 2026-11-19).** 중국 학습자를 위한 영어 읽기이되 아시아 시장에서 두루 쓸 제품이다. v0.8에서 화면을 영어로 바꾸고 책 속 이름을 영어 이름으로 바꿨다. 남은 물음은 6절에 있다.

## 4. 범위 안: 지금 만들어진 것 (v0.7)

### 4-1. 학생

| 기능 | 내용 | 정한 사람 |
|---|---|---|
| 단계별 서재 | 6단계, 모든 단계의 책이 늘 열려 있음 | 가정 (6단계) |
| 단계 진단 | 쉬운 글부터 읽고 두 문제를 모두 맞히면 다음 단계 글로. "추천 단계"로 알려 줌 | 가정 |
| 듣기 | 브라우저 음성으로 읽어 줌, 이어 듣기, 천천히 듣기 | 소리 품질은 나중 (사용자) |
| 낱말 뜻 | 낱말을 누르면 소리와 쉬운 영어 풀이. 선택 언어 묶음이 있으면 그 말의 뜻도 함께 | 영어는 사용자, 풀이 방식은 가정 |
| 소리 글자 표시 | 1단계 책에서 배우는 글자에 보라색 밑줄 | 색은 사용자 |
| 끊어 읽기 | 뜻 덩어리마다 `/` 표시 (규칙 기반) | 가정 (방향은 사용자의 chunk-reading) |
| 덩어리별 뜻 | 선택 언어 묶음에 들어 있을 때만 보임. 지금은 한국어 묶음에 시범 3권 | 가정 |
| 녹음 | 자기 목소리를 녹음해 들어 봄 (기기에만 남음) | 가정 |
| 다시 세우기 | 책마다 문장 3개를 조각으로 다시 세움 | 가정 |
| 확인 문제 | 책마다 5문항, 80% 통과, 틀리면 근거 쪽을 다시 봄 | 가정 |
| 독서 도장판 | 책마다 도장 네 개. 점수 없음 | 가정 |
| 단계 올라가기 | 한 단계에서 4권을 마치면 다음 단계 | 가정 |
| 내 낱말장 | 눌러 본 낱말이 모임, 뜻 가리고 맞혀 보기 | 가정 |

### 4-2. 선생님과 학부모

| 기능 | 내용 |
|---|---|

| 어디서 막히는지 | 자주 눌러 본 낱말, 틀리거나 다시 세우다 막힌 쪽 |
| 문제 유형별 정답률 | 세부, 낱말, 중심 내용, 순서, 추론 |

### 4-3. 콘텐츠

| 항목 | 수량 | 상태 |
|---|---|---|
| 단계 | 6 | 기준은 잠정 |
| 책 | 30권 (단계마다 5권), 203쪽 | AI가 쓰고 AI가 검수. **사람 검수 0권** |
| 확인 문제 | 150문항 | 같음 |
| 낱말 풀이 | 490개 (쉬운 영어) | AI가 새로 쓰고 다른 AI 모델이 검수. 사람 검수 전 |
| 단계 진단 글 | 6개 | 같음 |
| 낱말 그림 | 38종 (직접 그린 SVG) | 사람 검토 전 |
| 다시 세우기 문장 | 90개 | 규칙이 고름. 사람이 보지 않음 |
| 한국어 묶음(선택) | 낱말 뜻 490개, 책 제목 30개, 덩어리 뜻 3권 56개 | 기본 화면에서는 쓰지 않음. 화면 아래 "Word help" 또는 `?l1=ko` |
| 중국어 묶음(선택, 간체) | 낱말 뜻 490개, 책 제목 30개, 덩어리 뜻 3권 56개 | AI 초안. 중국어를 모국어로 쓰는 사람의 검수 전. 화면 아래 "Word help" 또는 `?l1=zh` |

수량은 개발 현황판과 책 검사 도구가 데이터를 세어 보여 주는 값이다.

### 4-4. 개발 도구와 문서

- 개발 현황판(`dev/`): 모든 책, 정답, 그림, 낱말, 할 일, 검수 기록, 사람 검수 도구, 기기 점검
- 책 검사 도구(`tools/check.html`): 단계 기준, 그림, 낱말 풀이, 다시 세우기, 풀이 누락 검사
- 문서: 단계 기준, 참고 서비스 관찰 기록(REA), 데이터 출처, 차별화 계획, 인계 문서, 상태

## 5. 범위 안이지만 아직 하지 않은 것

우선순위 순. 앞의 세 가지는 사람이 해야 한다.

1. **사람의 줄별 검수**: 검수 항목 401개(제목 30, 본문 203, 확인 문제 150, 단계 진단 18). 지금 0줄
2. **사람이 판단할 것 6건**: 2차 AI 검수에서 남긴 것
3. **끊어 읽기와 다시 세우기 확인**: 끊는 자리 273곳, 다시 세우기 90문장, 우리말 뜻 56개
4. 다시 세우기 문장을 책마다 사람이 지정하는 방법
5. 덩어리별 뜻을 나머지 27권으로 넓히기 (중국어, 한국어)
5. 중국어 묶음의 사람 검수 (낱말 뜻 490, 제목 30, 덩어리 뜻 56)
6. 책 늘리기. 소재는 중국 생활 소재(사용자, 2026-11-19). 목표 권수는 대기. 참고 서비스는 단계별 책만 1,500권 이상이라(공개 소개 자료) 권수로 견주지 않는다
6. 영어 낱말 풀이 490개와 낱말 문제 30개의 사람 검수
7. 아이가 실제로 써 보는 시험과 그 결과에 따른 규칙 조정
8. 학생에게 열기 전: 정답이 보이는 개발 현황판을 막고 사이트의 링크를 뺌
9. 참고 서비스 재확인 목록의 남은 것: 약관의 법률 검토, 개인정보 수집 항목, 앱 버전 기록

## 6. 결정 대기

| 무엇 | 왜 중요한가 |
|---|---|
| 학부모 화면의 언어 | 중국어 묶음은 낱말 뜻과 덩어리 뜻만 바꾼다. 화면 안내는 영어뿐이라 영어를 읽지 못하는 학부모에게는 맞지 않는다 |
| 중국어를 기본으로 켤지 | 지금은 영어만이 기본이고 화면 아래에서 고른다 |
| 레포 공개 범위 | 사용자는 비공개를 원한다. 무료 요금제에서는 비공개로 바꾸면 공개 사이트가 내려간다 |
| 현황판과 문서의 언어 | 개발 참여자용이라 한국어로 두었다. 영어로 바꿀지 |
| 한 단계 4권, 도장판, 활동 이름(Check) | v0.7에서 에이전트가 바꾼 것. 확정 전 |
| 레포 이름 learning-z | 참고 서비스 이름과 닮음. 바꾸면 공개 주소가 바뀜 |
| 서비스 이름 | ReadStep은 가칭 |
| 목표 책 수 | 단계마다 5권은 가정 |
| 6단계, 통과 80%, 단계 진단 규칙 | 모두 가정. 아이가 써 본 기록으로 다시 봐야 함 |
| 개발 현황판을 언제 숨길지 | 지금은 정답까지 공개됨 |
| 파닉스 사이트와의 역할 분담 | 1단계 "소리 읽기"가 겹침 |

## 8. 범위 밖: 하지 않는 것

- 참고 서비스의 책, 그림, 확인 문제, 수업안, 레벨 체계와 이름, 화면 디자인, 가격을 가져오는 것
- 참고 서비스에 가입하거나 체험판을 쓰는 것, 접근이 막힌 자료를 우회하는 것
- 인증이 필요한 읽기 지수(Lexile 등)와의 대응
- 외부 이미지, 외부 글꼴, 광고, 사용 분석 스크립트
- 학생 개인정보의 서버 수집 (지금은 서버가 없고, 기록은 각 기기의 브라우저에만 남음)
- 읽기 밖의 영역: 쓰기 과정, 과학 등 교과 콘텐츠, 교사 연수
- 모바일 앱 (지금은 웹만. 휴대폰 폭에서 동작함)

## 9. 제약과 원칙

- **독립 개발 원칙(REA)**: 공개된 자료만 관찰하고, 복제하지 않으며, 사실과 추론을 구분해 적는다 (`docs/REA_ANALYSIS.md`)
- **모르는 것은 모른다고 표시한다**: 책마다 "AI 검수만 / 사람 검수", 규칙마다 "잠정", 예시 데이터에는 "예시"
- **사용자 결정과 에이전트 가정을 섞지 않는다** (`docs/HANDOFF.md` 6절)
- **기술**: 빌드 없는 정적 HTML, CSS, JS. GitHub Pages. 서버와 계정 없음
- **화면**: 사용자가 준 색상 지침. 그림이 화려하므로 화면은 조용하게
- **언어**: 학생·선생님·학부모 화면과 책에 딸린 글은 영어. 다른 말은 선택 언어 묶음으로만 넣는다. 개발 현황판과 문서는 한국어
- **외부 공개, 전송, 삭제, 결제는 사용자 승인 뒤에**
